# java-lotto-precourse

간단하나 로또 발매기 프로그램입니다.

로또를 구매하여 당청여부를 확인하고, 수익률을 확인할 수 있습니다. 로또는 1,000원 단위로 구매할 수 있으며 1인당 최대 10,000장까지 구매 가능합니다. 로또 번호가 일치하는 개수만큼 등수가 결정됩니다. 당첨 기준과 금액은 아래와 같습니다.

- 1등: 6개 번호 일치 시 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 시 30,000,000원
- 3등: 5개 번호 일치 시 1,500,000원
- 4등: 4개 번호 일치 시 50,000원
- 5등: 3개 번호 일치 시 5,000원

수익률은 소수점 둘째 자리에서 반올림하며, 다음과 같이 계산됩니다.
```
수익률 = 당첨 금액 / 구매 금액
```


## 기능 목룍
### 로또 구매
#### 1. 가격 입력
- [x] 1인당 하루 최대 10,000장까지 구매 가능하다.
- [x] 로또 1장의 가격은 1,000원이다.

#### 2. 로또 발행
- [x] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- [x] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- [x] 로또 번호는 오름차순으로 정렬되어야 한다.

#### 3. 당첨 번호 및 보너스 번호 추첨
- [x] 추첨은 사용자가 진행하며 입력 받은 당첨 번호와 보너스 번호이다.
- [x] 로또 번호의 숫자 범위는 1 ~ 45까지이다.
- [x] 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.

### 당첨 안내
#### 1. 당첨 수량 및 수익률 공개
- [x] 당첨은 1등부터 5등까지 있으며 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- [x] 수익률은 소수점 둘째 자리에서 반올림한다.
- [x] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.

### 예외 상황
- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
- [x] 구매 금액이 1,000원 단위가 아닌 경우

#### 입력 예외 상황
- [x] 당첨 번호가 쉼표(,)로 구분되어 있지 않은 경우
- [x] 구매 금액이 숫자가 아닌 경우
- [x] 구매 금액이 -2^63 ~ 2^63 -1가 아닌 경우
